# ResoDiffusion
Reso Diffusion is a way to create ingame ui to interface with custom python files. with its main purpuse being for ai generating in Resonite, running locally on your own gpu with suport for image2image, use Stable Diffusion and other ai or create your own Python integrations.


### *Unreleased mod* still work in progress. But early release for people who want to try it.
I still have to add a lot of things befor i release it, but slightly lazy so give me a month or 3


# installation
- Resonite mod loader...
- Go to Resonite Folder, add a new folder called `ResoDiffusionIntegrations`
- Install one or multiple of the integrations listed below and put them inside ResoDiffusionIntegrations, create a folder containing the Python file or exe. The folder must be named after the integration, as the instructions say
- get ai generator UI from my public folder `resrec:///U-HamoCorp/R-e5c234a3-c4d4-4645-af54-7a80d388605c`
